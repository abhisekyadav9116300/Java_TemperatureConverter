# 🌡️ TemperatureConverter

A modern Java Swing-based **Temperature Converter** application with an attractive UI that instantly converts temperatures between **Celsius, Fahrenheit, Kelvin, and Rankine**.

## 📌 Features

- ✅ Convert between:
  - Celsius (°C)
  - Fahrenheit (°F)
  - Kelvin (K)
  - Rankine (°R)

- ✅ Real-time conversion while typing
- ✅ Modern Dark Theme UI
- ✅ Interactive Result Cards
- ✅ Formula display for every conversion
- ✅ Reference Temperature Table
- ✅ Rounded UI Components
- ✅ Input Validation
- ✅ Fast and Lightweight

## 📖 Conversion Formula Examples

### Celsius → Fahrenheit

```
°F = (°C × 9/5) + 32
```

### Fahrenheit → Celsius

```
°C = (°F − 32) × 5/9
```

### Celsius → Kelvin

```
K = °C + 273.15
```

### Celsius → Rankine

```
°R = (°C + 273.15) × 9/5
```

The application automatically displays the correct formula depending on the selected conversion.
